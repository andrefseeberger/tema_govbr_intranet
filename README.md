# Govbr Intranet

Versão: **1.0.1**. Identificador interno do tema: `govbr`.

Adaptação do tema GOVBR para uso na intranet, com pequenos ajustes para o Drupal 11.

## Autoria e ajustes

Não sou o desenvolvedor original deste tema. Minha contribuição se limita a
pequenos ajustes no tema existente:

- Ampliação da declaração de compatibilidade para permitir o uso no Drupal 11.
- Remoção da dependência de CDN para os recursos do tema, passando a servir o
  CSS e as fontes do Font Awesome localmente. Bootstrap e Rawline já eram locais.
- Pequenos ajustes de CSS para padronizar espaçamentos, títulos, campos
  obrigatórios e imagens dos artigos.
- Adequação de caminhos de imagens ao diretório do tema.

Os créditos de desenvolvimento original presentes no código foram preservados.

## Descrição original do tema

O texto abaixo reproduz a descrição original, preservando seu contexto histórico.

> O Governo Federal desenvolveu um projeto de Identidade Digital de Governo que busca padronizar os portais dos órgãos públicos federais e alinhar as informações para otimizar a comunicação com o cidadão. 
> 
> O padrão de formatação das páginas dos sítios eletrônicos da MB deve acompanhar as recomendações de estilo definidas no Guia de Estilo de Sítios Portais da Identidade Padrão de Comunicação Digital do Governo Federal e atender aos padrões de usabilidade e acessibilidade do Governo Federal.
